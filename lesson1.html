03 / 遊戲換成生活 25–40 分

你本來就懂故事

遊戲裡的任務、危機、反殺，在故事裡叫什麼？

把遊戲經驗配到故事名稱；下方會揭曉生活對照。

先用自己的經驗回答

只用手槍 → 遇到對手 → 被追 → 逆轉 → 勝利。

揭曉答案

任務＝主題；發現對手＝事件；快輸＝衝突；反殺＝高潮；勝敗＝結果。

Roblox／RIVALS

只用手槍 → 遇到對手 → 被追 → 逆轉 → 勝利。

換成生活

三次投籃挑戰 → 第一投 → 連續失敗 → 最後投進 → 挑戰成功。

主題／事件／衝突／高潮／結果

換了題材，觀眾仍然需要知道「在做什麼、發生什麼、最後怎樣」。

  • 只用手槍的任務 → 主題 → 運動：三次投籃挑戰
  • 發現對手 → 事件 → 旅遊：抵達景點
  • 被追、快輸了 → 衝突 → 美食：蛋糕沒有成形
  • 最後反殺 → 高潮 → 運動：最後一球逆轉
  • 勝利或失敗 → 結果 → 開箱：測試後是否好用

教師備註

25–30 分：配對後請孩子說一個生活對應。反殺是本案例的高潮，不是每部影片都要戰鬥或逆轉。安靜的風景揭曉、實用答案也可以是重點。

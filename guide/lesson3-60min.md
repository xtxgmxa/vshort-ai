# 第三堂：在剪映完成第一支短片

對象：國小中高年級。建議 60 分鐘；若只有 50 分鐘，略過獨立挑戰的第二次匯出，聲音由老師示範，仍保留第一次匯出與播放驗收。

第一堂練觀眾與故事判斷，第二堂練模擬操作；第三堂用真實剪映把判斷做出來。只用 1 分鐘銜接舊課，不再逐關重講跑酷或勇者議題。

## 課前要備好

- 每台電腦確認剪映專業版／CapCut 電腦版能開啟、匯入與匯出；依教室版本確認功能名稱。教材示意圖不是軟體截圖，不能當固定座標教學。
- 自備三支同主題影片，共約 30–45 秒：01 準備（含片頭等待）、02 試飛（中間有一段等待，前後都有要留的動作）、03 落地與反應。原片需真的有可修剪處。本教材不附實拍影片。
- 自備一段可使用的背景音樂；影片若有「成功了」等反應聲，音量課更容易比較。若沒有原聲，不要求孩子找不存在的人聲。
- 用同一組素材先做一支 15–30 秒範例 MP4：有順序、去掉等待、一句開頭字幕、音樂收在片尾。不用特效也能完成。
- 素材放同一個容易找的資料夾；指定作品輸出資料夾。用代號命名即可。
- 可換投籃、積木或自有遊戲錄影，替換素材名稱與字幕例句；本堂不要求再創作腳本。

## 每一段的帶課節奏

1. 老師先 CUE 一個具體問題，請孩子指位置、說要先選誰。
2. 示範一小段，孩子切回真正剪映跟做。每頁最多三個動作步驟。
3. 看作品結果驗收，再請一位孩子說改變了什麼。不只問「懂不懂」。

第一次教可用一般模式，顯示操作步驟。複習時按右上「CUE 模式」，先藏起步驟、位置亮框、驗收提示與選擇題，孩子回答後再按「看解答」。介面四區按鈕在未揭曉前暫時停用，避免提示答案。

「老師備課」顯示每頁帶法。孩子回答時可關閉老師備註，避免投影洩漏提示。頁碼能直接跳轉；左右鍵也可切頁（輸入與操作按鈕時不攔截）。勾選為本次開頁的實作自查，重新整理會重置，不代表網頁驗證過剪映。

## 60 分鐘安排

| 時間 | 真正要做的事 | CUE 與觀察點 |
| --- | --- | --- |
| 00–05 | 看原片／成品，建立專案 | 今天帶走什麼？能用播放器打開的 MP4。 |
| 05–09 | 指出素材庫、預覽窗、時間軸、設定區 | 要改第二段，先選誰？老師用有素材的專案示範。 |
| 09–13 | 匯入三段、拖到時間軸、設定直式比例 | 有縮圖為何沒影片？能分清素材與作品。 |
| 13–17 | 選取、播放頭、播放暫停、復原 | 看到試飛為何刪了準備？分清選取外框與播放頭。 |
| 17–20 | 排三段、檢查接縫 | 移動抓中間；檢查是否留黑畫面。 |
| 20–24 | 修剪片頭等待 | 頭尾用邊緣；沒有讓動作變快。 |
| 24–31 | 等待前後分割、選中間刪除 | 兩刀只拿掉中間，前後都在。 |
| 31–37 | 一句字幕、位置、出現時間 | 改內容／位置／時間，分別看哪裡？ |
| 37–41 | 加音樂、選對聲音、修到片尾 | 音樂太大，不是把整台電腦關小。 |
| 41–47 | 完整預覽、匯出、開檔 | 專案與影片檔不同；能找到輸出資料夾。 |
| 47–57 | 四題情境題、兩人輪流獨立修改 | 不跟著老師滑鼠，也能改字幕時間或音量。 |
| 57–60 | 播作品、說出改動 | 「我選了＿＿，用了＿＿，所以＿＿。」 |

時間是節奏建議，不是倒數通關。孩子剪得慢，先完成基本順序、修剪、一句字幕與匯出；音樂可老師示範，加分操作留到下次。完成後才選縮放或變速，不必每人都做。

## 遇到問題，先這樣問

- 「你現在選到誰？」先看外框，不只看預覽窗。
- 「你要改內容、位置，還是出現時間？」不要把字幕的不同操作混在一起。
- 「頭尾不要，還是中間不要？」分別選修剪或兩次分割再刪除。
- 「改完在哪裡看得出來？」要求播放修改處，確認沒有切斷放飛或落地。
- 「刪錯了怎麼救？」找復原，Windows Ctrl+Z／Mac Command+Z，再做一次。
- 「關掉剪映後去哪裡看作品？」找到 MP4，以播放器驗收，不只看專案列表。

## 課末檢核

網頁選擇題答對只代表理解。老師實際看孩子能否：指出四區、分清選取與播放頭、自己完成修剪或分割刪除、改字幕出現時間、找到可播放的匯出檔。

需要提示時用「先選誰」提示，不直接代按。讓搭檔輪流操作，避免只有一人會剪。對尚未完成的孩子記下卡住的操作，下堂先補練。

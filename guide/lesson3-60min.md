# 第三堂：在剪映完成第一支短片

對象：國小中高年級。新增 15 分鐘「影片規格小教室」後，完整建議 75 分鐘。若只有 60 分鐘，使用文末精簡走法；保留真正操作、匯出與播放驗收。

第一堂練觀眾與故事判斷，第二堂練模擬操作；第三堂用真實剪映把判斷做出來。只用 1 分鐘銜接舊課，不再逐關重講跑酷或勇者議題。

## 課前要備好

- 每台電腦確認剪映專業版／CapCut 電腦版能開啟、匯入與匯出；依教室版本確認功能名稱。教材示意圖不是軟體截圖，不能當固定座標教學。
- 自備三支同主題影片，共約 30–45 秒：01 準備（含片頭等待）、02 試飛（中間有一段等待，前後都有要留的動作）、03 落地與反應。原片需真的有可修剪處。本教材不附實拍影片。
- 自備一段可使用的背景音樂；影片若有「成功了」等反應聲，音量課更容易比較。若沒有原聲，不要求孩子找不存在的人聲。
- 用同一組素材先做一支 15–30 秒範例 MP4：有順序、去掉等待、一句開頭字幕、音樂收在片尾。不用特效也能完成。
- 素材放同一個容易找的資料夾；指定作品輸出資料夾。用代號命名即可。
- 可換投籃、積木或自有遊戲錄影，替換素材名稱與字幕例句；本堂不要求再創作腳本。

## 每一段的帶課節奏

1. 老師先 CUE 一個具體問題，請孩子指位置、說要先選誰。
2. 示範一小段，孩子切回真正剪映跟做。每頁最多三個動作步驟。
3. 看作品結果驗收，再請一位孩子說改變了什麼。不只問「懂不懂」。

第一次教可用一般模式，顯示操作步驟。複習時按右上「CUE 模式」，先藏起步驟、位置亮框、驗收提示與選擇題，孩子回答後再按「看解答」。介面四區按鈕在未揭曉前暫時停用，避免提示答案。

「老師備課」顯示每頁帶法。孩子回答時可關閉老師備註，避免投影洩漏提示。頁碼能直接跳轉；左右鍵也可切頁（輸入與操作按鈕時不攔截）。勾選為本次開頁的實作自查，重新整理會重置，不代表網頁驗證過剪映。

## 75 分鐘安排

| 時間 | 真正要做的事 | CUE 與觀察點 |
| --- | --- | --- |
| 00–05 | 看原片／成品，建立專案 | 今天帶走什麼？能用播放器打開的 MP4。 |
| 05–08 | 畫面比例：橫／直／方畫框 | 1920×1080 與 1080×1920 一樣嗎？ |
| 08–11 | 畫面尺寸：像素方格、常見解析度 | px 是像素單位；放大不保證補回細節。 |
| 11–14 | 幀率：翻頁書、30／60 fps | 同樣 10 秒，幀率多不代表播得快。 |
| 14–17 | 影片檔案格式：主比 MP4／MOV，再認 AVI／MKV／WebM | 常見用途與讀取支援不同，不能只靠格式判斷畫質。 |
| 17–18 | 檔案容量：MB／GB，最後看分類表 | 容量、格式、尺寸、幀率是不同分類。 |
| 18–20 | 素材／專案／匯出三張卡、不同軟體流程 | 自動設定是否符合今天要的作品？ |
| 20–24 | 指出素材庫、預覽窗、時間軸、設定區 | 要改第二段，先選誰？老師用有素材的專案示範。 |
| 24–28 | 匯入三段、拖到時間軸、設定直式比例 | 有縮圖為何沒影片？能分清素材與作品。 |
| 28–32 | 選取、播放頭、播放暫停、復原 | 看到試飛為何刪了準備？分清選取外框與播放頭。 |
| 32–35 | 排三段、檢查接縫 | 移動抓中間；檢查是否留黑畫面。 |
| 35–39 | 修剪片頭等待 | 頭尾用邊緣；沒有讓動作變快。 |
| 39–46 | 等待前後分割、選中間刪除 | 兩刀只拿掉中間，前後都在。 |
| 46–52 | 一句字幕、位置、出現時間 | 改內容／位置／時間，分別看哪裡？ |
| 52–56 | 加音樂、選對聲音、修到片尾 | 音樂太大，不是把整台電腦關小。 |
| 56–62 | 完整預覽、匯出、開檔 | 確認直式 1080×1920、課堂指定 fps 與 MP4；能找到檔案。 |
| 62–72 | 六題輪流回答、兩人輪流獨立修改 | 不跟著老師滑鼠，也能改字幕時間或音量。 |
| 72–75 | 播作品、說出改動 | 「我選了＿＿，用了＿＿，所以＿＿。」 |

時間是節奏建議，不是倒數通關。孩子剪得慢，先完成基本順序、修剪、一句字幕與匯出；音樂可老師示範，加分操作留到下次。完成後才選縮放或變速，不必每人都做。

## 遇到問題，先這樣問

- 「這個數字的單位是什麼？」px 是像素，fps 是每秒幾格，s 是秒，MB／GB 是容量，Mbps 是每秒資料量。
- 「這是原片、工作畫框，還是匯出成品的規格？」不要把三者混成一件事。
- 「先讀寬，還是高？」先寬後高；16:9／9:16 是比例，不是 px 尺寸。

- 「你現在選到誰？」先看外框，不只看預覽窗。
- 「你要改內容、位置，還是出現時間？」不要把字幕的不同操作混在一起。
- 「頭尾不要，還是中間不要？」分別選修剪或兩次分割再刪除。
- 「改完在哪裡看得出來？」要求播放修改處，確認沒有切斷放飛或落地。
- 「刪錯了怎麼救？」找復原，Windows Ctrl+Z／Mac Command+Z，再做一次。
- 「關掉剪映後去哪裡看作品？」找到 MP4，以播放器驗收，不只看專案列表。

## 課末檢核

網頁選擇題答對只代表理解。老師實際看孩子能否：指出四區、分清選取與播放頭、自己完成修剪或分割刪除、改字幕出現時間、找到可播放的匯出檔。

需要提示時用「先選誰」提示，不直接代按。讓搭檔輪流操作，避免只有一人會剪。對尚未完成的孩子記下卡住的操作，下堂先補練。

## 規格教學重點與 60 分鐘精簡走法

分類要分開教：MP4／MOV／AVI／MKV／WebM 是影片容器格式；px 是畫面像素的單位；fps 是每秒張數的單位；MB／GB 是容量單位。不要把它們列成同一排「影片格式種類」。最後的分類表才用來整理差別。

格式頁主教 MP4 與 MOV：常見分享與交付會遇到 MP4，Apple 拍攝與剪輯流程常遇到 MOV；實際讀取還要看軟體與編碼。其他三種只認常見用途：AVI 常見於較舊影片、MKV 可裝多音軌與字幕、WebM 用於網路影音。不要說 MOV 一定比 MP4 清楚、大或無損，也不要說改副檔名就轉好格式。

用「素材是照片、專案是畫框、匯出是交出去的成品」串起來。剪映在原始／自適應模式可能依素材設定畫布，但也能手動改；PR 常先確認序列、達芬奇常先確認專案／時間軸，兩者也都有依素材配合部分設定的路徑。不要教成完全相反或只有一種流程。

今天老師可統一準備 30 fps 素材、以 1080×1920、30 fps、MP4 示範；這是本課選擇，不是所有影片的唯一正確答案。若原片為 25／60 fps，先由老師決定課堂規格。匯出視窗只顯示「1080p」時，也要看方向或輸出尺寸，不能把它當成永遠 1920×1080。

60 分鐘版：00–05 看成品並開專案；05–17 規格小教室（每頁只做一次互動、位元率與編碼補充略過）；17–23 認位置並匯入；23–28 選取、播放頭與排序；28–39 修剪及兩刀刪中間；39–45 字幕；45–48 音量由老師示範；48–54 匯出開檔；54–58 挑兩題 CUE，加一次字幕長度獨立修改；58–60 分享。原頁標示是完整版節奏，精簡課依此表帶，不必改頁面計時。

不要考背誦所有數字。能判斷橫直、辨認單位，並知道自動設定也要檢查，就是這段的目標。像素格子與 fps 圓點是減量示意，不是影像品質或流暢度的實測。

功能用官方文件交叉確認，課堂按鈕名稱與面板位置以實際安裝的剪映版本為準。

# 剪輯 SOP（剪映用）

下一堂正式進剪映時，照這個順序做。先有觀念，再開軟體。

## 剪之前

1. 想好觀眾是誰、一句話主題是什麼。
2. 寫三格腳本（開始／過程／結果），秒數合計 30。
3. 確定 Hook：開頭給任務或限制。

## 剪的時候

1. **選材**：先刪沒新事情的等待、重複。只留有線索和情緒的。
2. **分割**：把不要的段落切開、刪掉（對應「節奏」）。
3. **排順序**：按主題→事件→衝突→高潮→結果排好。
4. **速度**：推進的地方快帶過，重要瞬間可以停半拍。
5. **字幕**：字少放中間大字，字多分兩行放下面，重點字放大變色。不擋人臉和重點。
6. **音樂**：開頭給氣氛，高潮推上去，結果前可以安靜。音樂服務情緒，不蓋過人聲。

## 剪之後

1. 自己看一次：開頭有沒有讓人想留下？故事看懂嗎？結果有交代嗎？
2. 給同學看一次，問他「你看懂什麼」。
3. 改完再匯出。

## 觀念 → 剪映功能對照

| 觀念 | 剪映功能 |
|---|---|
| 選材 | 刪除片段 |
| 節奏 | 分割、速度 |
| 故事順序 | 拖曳排序 |
| 字幕 | 文字軌道 |
| 音樂 | 音軌 |
| 視覺焦點 | 放大、裁切 |
| Hook | 開頭片段放最前面 |

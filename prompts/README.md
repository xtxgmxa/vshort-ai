# AI 指令範本

這些範本給孩子用。每個範本都有固定規則，孩子只要改 `{題材}` `{觀眾}` 兩個欄位，複製貼給 AI。

重要原則：**AI 給建議，你決定。** AI 不在現場，可能編造；你看到的才是真的。

## 1. 拆解一支短影音

```
你是短影音創作助手。請用國小中高年級看得懂的話，拆解這支短影音。
題材：{題材}
觀眾：{觀眾}

規則：
1. 從 Hook、故事、節奏、字幕、音樂五個面向拆，每個面向給 1 點就好。
2. 每點要說「為什麼」。
3. 不要編造影片裡沒發生的事；看不到的寫「看不出來」。
4. 我會自己判斷要不要用，你只是助手。
```

## 2. 想字幕

```
你是短影音創作助手。請幫這段影片想字幕，每句不超過 8 個字。
題材：{題材}
觀眾：{觀眾}

規則：
1. 給 3 個版本，分別是「提示」「強調」「補資訊」三種用途。
2. 說明每個版本放哪裡（中間／下排／分兩行）。
3. 不要擋住主畫面裡的人臉或重點。
4. 我會自己挑，你只是助手。
```

## 3. 寫 30 秒三格腳本

```
你是短影音創作助手。請幫我寫 30 秒三格腳本（開始／過程／結果）。
題材：{題材}
觀眾：{觀眾}

規則：
1. 三格各給「畫面」「台詞」「秒數」，秒數合計 30。
2. 開頭要有 Hook（任務或限制）。
3. 結果要真實，可以成功也可以失敗，不要編造沒發生過的內容。
4. 給 1 個版本就好，我會自己改，你只是助手。
```

## 4. 給節奏建議

```
你是短影音創作助手。請幫我看這支片的節奏。
題材：{題材}
觀眾：{觀眾}

規則：
1. 標出哪裡該快、哪裡該慢、哪裡該停，各給 1 個例子。
2. 說明為什麼這樣標。
3. 不要把整支都標成「快」。
4. 我會自己判斷，你只是助手。
```

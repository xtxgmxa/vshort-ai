# 小導演任務：短影音剪輯 × AI 互動課

作者 Mr.Bill。

## 上傳 GitHub Pages

解壓縮後，把這個資料夾裡的全部檔案放在 GitHub 儲存庫根目錄（入口是 index.html），不要只上傳 lesson1.html。這是靜態教材，不需要安裝或建置。

在儲存庫 Settings → Pages 選擇 Deploy from a branch，選擇你的分支與根目錄，保存後使用 GitHub 提供的網站網址。若帳號或儲存庫條件不同，以 GitHub Pages 官方說明為準。

## 導演工具箱

首頁與課程頁都有工具箱入口，提供 Hook 產生器、三格腳本、字幕建議、節奏標記、AI 指令、拆片檢核與簡繁轉換。工具均在本機處理。

簡繁轉換採用本機 OpenCC 字詞字典，支援繁體（台灣字形）與簡體雙向轉換，保留換行、英文、數字及表情符號。首次使用才載入字典，不上傳輸入文字。

## 第二堂冒險課

建議一小時節奏：剪輯操作 20 分鐘、勇者遠征 20 分鐘、跑酷與鏡頭偵探 10 分鐘、四格短片創作與交換觀看 10 分鐘。這是上課安排，依孩子操作與討論速度調整；沒有倒數鎖住課程。

「回聲王國」為原創回合制勇者冒險：探索地圖、旅人對話、四個地區與四隻怪物，共十二個剪輯戰鬥回合。透過分割與刪除、排序、景別、字幕、音量、變速以及完整預覽破盾反擊；失誤會掉血，可回營地補血，也可重玩地區。四顆星石集齊可下載冒險素材筆記。勇者遠征進度在重新整理後重置。

戰鬥有可播放的故事時間軸、字幕軌，以及選擇性合成音軌試聽。預覽從頭完整播放後，才能通過需要完整預覽的回合；移播放頭跳到結尾不算完成。角色、怪物與場景是程式原創繪製，採經典勇者 RPG 形式，未使用《勇者鬥惡龍》官方角色或素材。離開畫面或頁面時暫停。

最後創作區有四格可填寫的短片計畫，下載 .md 後帶進下一堂剪映實作。

第二堂主畫面是剪輯任務控制台，包含素材庫、角色動畫預覽、影片／字幕／聲音軌，以及九個操作任務：選材、排列、分割刪除、修剪、字幕、景別、變速、音量、首映檢查。每次修改會反映在預覽與時間軸上。片段可拖曳或以按鈕排序；分割按播放頭位置計算來源切點，修剪保留來源時間範圍，變速獨立改變播放速度。

前三關是獨立基本操作練習；第四關起循「下一個剪輯任務」繼續，會沿用前一關的修剪、字幕、景別、變速和音量成果，最後下載自己的 .md 操作計畫。直接點任務卡則載入該關的練習素材。九枚操作徽章存於同一分頁 sessionStorage；重新整理會重置操作中的素材與設定。

音軌可選擇試聽，使用瀏覽器合成背景音和成功提示音；未勾選時不發聲。角色使用分肢繪製，依演出進行跑步擺臂跨步、起跳、落地和歡呼。原本四個世界收在「更多素材冒險」補充區，收合時停止其動畫。

第二堂有四個世界：積木跑酷（3 個錄影站）、鏡頭偵探（3 個景別任務）、剪輯工作站（5 步流程）、像素冒險（4 個判斷任務）。可切換世界，不必先通關才能上課。

積木跑酷使用原創 Canvas 2.5D 繪製、重力與跳躍碰撞、視差背景、粒子、畫面震動；鏡頭偵探用場景縮放模擬景別。特效可關閉，系統要求減少動態時預設關閉。跑酷可開啟自動跳躍輔助，將注意力放在鏡頭判斷。遊戲不是 Roblox 客戶端或真正的三維場景。

剪輯工作站練習選材、按鈕調整順序、滑桿修剪、字幕、預覽與輸出檢核。輸出為 .md 剪輯計畫，不產生影片檔；可帶進下一堂剪映實作。新世界的練習在重新整理後重置，像素冒險徽章仍依下述方式保存。

方向鍵或 WASD 移動、Enter 和附近角色對話；觸控可用方向按鈕、點旗子或任務卡。四個任務練習刪除等待、保留原因與線索、字幕位置、結果停留時間。試映室可播放 12 秒原始版與 8 秒剪輯版，切換字幕位置並暫停比較。畫面皆為原創程式繪製的像素遊戲模擬。

四枚徽章保存在同一分頁的 sessionStorage，重新整理可保留，不重複累積經驗值。通關後可下載 .md 剪輯筆記，銜接剪映實作；「重新冒險」會清除本堂徽章。

## AI 指令與規範

- `prompts/`：給孩子用的固定格式 AI 指令範本，只要改題材與觀眾兩個欄位。
- `guide/`：剪輯 SOP、字幕規則、AI 使用原則的 .md 規範，同時是上課講義。

## 第一堂授課互動

- 左右拖動頁面空白處換頁；按鈕與鍵盤也可換頁。
- 每段答案可拖動滑桿逐步拉開。
- 第 5 段有真實時間／影片時間滑動比較。
- 第 6 段拖曳流程階段到正確位置。
- 第 8 段拖素材到時間軸，再拖曳調整順序；播放分鏡會依你排列的順序。
- 第 9 段拖曳故事名稱到遊戲事件，按檢查看理由。

拖曳也支援觸控；鍵盤與按鈕替代操作保留。文字分鏡預演不是遊戲實拍影片。教材與互動可離線使用，外部示範連結需要網路。重新整理會清除作答；三格腳本可下載保存。
